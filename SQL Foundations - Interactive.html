FROM FactOnlineSales f
JOIN DimCustomer c ON f.CustomerKey = c.CustomerKey
JOIN DimStore   s ON f.StoreKey    = s.StoreKey
WHERE c.Name = 'Priya Shah' AND s.StoreName = 'Downtown';

Module 6

Transactions

Placing an order means two things must happen together: insert the order, and reduce inventory. A transaction guarantees both happen, or neither does.

BEGIN TRANSACTION
INSERT INTO FactOnlineSales (new order row)
UPDATE DimProduct SET StockQty = StockQty - 1
COMMIT / ROLLBACK
